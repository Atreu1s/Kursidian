Назначение программы

Kursidian — онлайн-приложение для структурирования мыслей. Оно объединяет менеджер задач и систему заметок в одном окне, чтобы не переключаться между разными инструментами.

Приложение рассчитано на одного пользователя, работает локально и хранит все данные в файле app.db рядом с исполняемым файлом.

Условия выполнения: операционная система Windows, Linux или macOS, браузер с поддержкой HTML5, свободный порт 8080, около 50 МБ дискового пространства.

Обзор

Раздел «Обзор» — стартовая страница. Он показывает четыре счётчика (всего задач, выполнено, заметок, тегов), полосу прогресса и четыре панели:

  • дедлайны в ближайшие три дня;
  • заметки, созданные за последние семь дней;
  • десять самых используемых тегов с разбивкой по заметкам и задачам;
  • теги, которые пока не привязаны ни к одной записи.

Каждая панель построена на отдельном SQL-запросе, поэтому обзор всегда отражает текущее состояние базы данных.

Задачи

Кнопка «Новая задача» открывает окно создания. Заголовок обязателен, описание, дедлайн и теги — по желанию.

  • Квадрат слева от задачи переключает состояние «выполнено» и «не выполнено» без перезагрузки страницы.
  • Кнопка «Изменить» открывает форму редактирования заголовка, описания, дедлайна и набора тегов.
  • Кнопка «Удалить» запрашивает подтверждение и удаляет задачу вместе со связями с тегами.
  • Вкладки «Все», «Активные» и «Выполненные» фильтруют список.

Просроченный дедлайн у невыполненной задачи подсвечивается красным.

Заметки

Кнопка «Новая заметка» открывает окно создания: заголовок, содержимое и теги. Переносы строк в тексте сохраняются.

  • Поле поиска над списком ищет по заголовку и содержимому заметок.
  • Кнопка «Изменить» открывает полный текст заметки для правки; дата изменения обновляется автоматически.
  • Кнопка «Удалить» запрашивает подтверждение.

В карточке показывается фрагмент текста; полный текст доступен в окне редактирования.

Теги

Тег — общая точка связи между заметками и задачами. У тега есть название и цвет, который используется во всём интерфейсе.

  • Кнопка «Добавить» создаёт тег; название должно быть уникальным.
  • Нажатие на тег открывает страницу со всеми заметками и задачами, которым он присвоен.
  • Числа справа от тега — количество заметок и задач с этим тегом.
  • При удалении тега заметки и задачи сохраняются, исчезают только связи.
Поиск

Раздел «Поиск» ищет одновременно по заметкам и задачам и показывает результаты двумя колонками.

Поиск нечувствителен к регистру первой буквы: запрос «проект» находит и «Проект», и «проект». Строка поиска доступна из любого раздела в верхней панели, быстрый переход к ней — клавиша /.

Сообщения оператору
  • «Заголовок задачи обязателен» / «Заголовок заметки обязателен» — форма отправлена с пустым заголовком, заполните поле и повторите отправку.
  • «Название тега обязательно» — пустое название тега.
  • «Запись не найдена» — запись была удалена в другой вкладке, обновите страницу.
  • «Внутренняя ошибка сервера» — ошибка работы с базой данных; подробности выводятся в консоль, где запущено приложение.
  • «Тег с таким названием уже существует» — название тега должно быть уникальным, выберите другое.

Приложение останавливается сочетанием Ctrl + C в окне запуска. Файл базы данных app.db при этом сохраняется; удаление файла приведёт к повторному созданию базы с тестовыми данными при следующем запуске.
